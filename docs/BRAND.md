# KS-LEARN brand guide

**Small beginnings. Lasting growth.**
**छोटी शुरुआत, पक्की सीख**

Version 1.0 · applies to v2.1 of the app.

---

## 1. The idea

KS-LEARN is a **personal mastery app for one child, on one device, offline**. Class 3 to 9, Hindi and
English. No account, no ads, nothing leaves the phone.

The brand stands on one image: **a seed that already contains the tree**. Fifteen minutes a day is a
small beginning; a mastered skill that stays for years is the lasting growth. Every asset in this kit
is built from that single thought — the seed, its shadow, and the sprout that comes out of it.

| | |
|---|---|
| **Positioning** | The quiet tutor that fits in a pocket. Not a game, not a coaching class: a daily habit. |
| **Promise** | Small beginnings. Lasting growth. |
| **Personality** | Warm, patient, exact. A good teacher, not a hype machine. |
| **Audience** | Parents in India with a child in class 3–9 and one shared phone. Secondarily: teachers who print packs. |
| **Proof** | Works in aeroplane mode · 8 subjects, 100+ skills · progress stored on the device · no accounts, no ads, no tracking |
| **Never** | Stars-and-stripes hype, exam fear, "topper" framing, streak shaming, data collection. |

## 2. The mark

The mark is **one almond seed carrying a three-leaf sprout**: the seed is the small beginning, the
sprout is the growth, the stem ties the two together. It is drawn flat — three greens, one warm
amber, no gradients — so it survives a 16 px favicon, one-ink print, a stamp and embroidery.

- **Seed** — the almond silhouette, warm amber. Pointed at the tip, round at the base, like a real
  date pit. One crease is drawn inside it; nothing else.
- **Sprout** — two side leaves and an apex leaf on a tapered stem. The stem enters the seed, so the
  two halves read as one plant.
- **Tilt** — the composition is set on a 4° tilt. Never straighten it, never tilt it further.

### Lockups

The **wordmark** is `KS-LEARN`, set in the display sans at weight 800, tracking −1 %, one line. The
hyphen is **always sprout green** — it is the one coloured character in the wordmark and the reason
the name reads as a promise rather than a code. Never break the wordmark into two lines, never
remove the hyphen, never set it in another colour.

- **Horizontal lockup** (default): mark left, wordmark right, optional tagline underneath. Use
  everywhere there is width: headers, letterheads, slides, the app's welcome screen.
- **Stacked lockup**: mark above, wordmark below, tagline underneath. Use for square and vertical
  formats: stickers, seals, certificate footers, app-store crops.
- **Mark alone**: use when the name is already present (app icon, favicon, favicon-size, avatar,
  watermark) or when space is under 120 px wide.

### Clear space and minimum sizes

- **Clear space** = the width of the seed (`X`) on all four sides. Nothing enters it: not text, not
  a photo edge, not another logo.
- **Minimum sizes** — mark: 24 px / 8 mm. Horizontal lockup: 140 px / 40 mm. Stacked lockup:
  96 px / 28 mm. Below 24 px use the app icon, never a shrunken lockup.

### Colourways

Approved backgrounds: **cream `#FBF7EF`**, **sand `#F3E7D3`**, **white**, **midnight `#0B1430`**.
On dark, use the dark lockup — the wordmark flips to paper white and the tagline to 66 % white.
Do not place the mark on a busy photo; if a photo is unavoidable, put it on a cream plate at 90 %
opacity or use the one-colour mark in white.

### Misuse

Never: recolour the mark outside the palette · stretch, squash or rotate it beyond the built-in 4°
tilt · add a gradient, glow, bevel, drop shadow or outline · put it in a box it does not belong to ·
redraw the leaves by hand · set the wordmark in a different typeface · pair the mark with a second
logo of equal weight · use the mark as a letter "K" inside another word.

mark. Always keep at least 4.5:1 contrast for text (`#0A5C40` on `#FBF7EF` ≈ 7:1, `#59637A` on
`#FBF7EF` ≈ 5.4:1).

## 4. Typography

The app ships **no webfonts** — a deliberate security and offline decision. Brand typography follows
the same discipline: use the reader's own system sans, and let it be good.

| Role | Size / weight | Notes |
|---|---|---|
| Wordmark | 800, tracking −1 % | Always one line, always `KS-LEARN`. |
| Display / h1 | 800–700, tracking −0.5 % | `text-wrap: balance`, max 2 lines. |
| Body | 400, 17 px / 1.55 | 60–70 characters per line. |
| Tagline | 500–600, +0.5 % tracking | Sentence case, full stop. Both languages. |
| Eyebrow | 700, uppercase, tracking +6 % | One or two words only. |

Stack: `Inter, Segoe UI, system-ui, -apple-system, Roboto, Noto Sans, Noto Sans Devanagari,
Nirmala UI, sans-serif`. Devanagari must always have `Noto Sans Devanagari` or `Nirmala UI` in the
stack and 5–8 % extra line-height. Never set Hindi in a Latin face, never letterspace Devanagari.

## 5. The tagline

**English:** Small beginnings. Lasting growth.
**Hindi:** छोटी शुरुआत, पक्की सीख

- Always both languages together in India-facing material; English first, Hindi under it in sprout
  green. One language is allowed only where space physically forbids it (a 320 px banner).
- Sentence case, full stop after "growth", comma in Hindi. Never all-caps, never a third line.
- Keep it a statement, not a claim: no exclamation mark, no "guaranteed", no "fastest".
- Approved short forms for tight spaces: **Small beginnings.** (campaign lines) and
  **छोटी शुरुआत** (stickers). Nothing else.

## 6. Voice

Short sentences. Concrete numbers. A parent talking to a parent.

| Say | Not |
|---|---|
| "15 minutes a day. One skill at a time." | "Revolutionary adaptive AI learning!" |
| "Works in aeroplane mode." | "Cloud-synced everywhere." |
| "Your child's progress stays on this phone." | "We value your privacy." |
| "Class 3–9 · Hindi and English" | "All classes, all boards" |
| "A seed is not a small tree. But it is the whole tree." | "Unlock your child's true potential." |

Three pillars, in this order: **habit** (small, daily, finishable) · **mastery** (a skill is learned
when it can be recalled a week later) · **privacy** (no account, no ads, nothing leaves the device).

## 7. Applications

- **App icon** — midnight tile, 112 px radius at 512 px, glyph in the middle third.
  `assets/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` (60 % safe circle),
  `apple-touch-icon.png` (180 px, no rounding: iOS rounds it).
- **Favicon** — `assets/favicon.svg`, also inlined in the single-file build as a data URI.
- **Welcome screen** — mark + wordmark + tagline above the setup form. This is the only place the
  full lockup appears inside the app.
- **Sharing card** — `assets/brand/social-card.png`, 1200 × 630, published as `og-image.png`.
  Wordmark and both taglines on the left, mark on the right at 1.5× the wordmark height.
- **Key visual** — `assets/brand/brand-hero.jpg`: one almond seed on warm sand, its shadow rising
  into a full tree. Type goes in the lower third, left aligned, never over the seed. Children appear
  in the product, not in the brand imagery.
- **Poster** — `assets/brand/campaign-poster.jpg`, A4 at 150 dpi: key visual on top, the three
  pillars and the proof line underneath. `node tools/make-poster.mjs` rebuilds it.
- **Print** — Packs, worksheets and certificates use cream paper, ink text, the stacked lockup at
  the foot, and no more than 8 % ink coverage from the brand itself.

## 8. Asset inventory and regeneration

```
assets/
  favicon.svg   icon-192.png   icon-512.png   icon-maskable-512.png   apple-touch-icon.png
  brand/
    logo-mark.svg  logo-mark-mono.svg  logo-mark.png  logo-mark-transparent.png
    logo-lockup.svg  logo-lockup.png  logo-lockup-tagline.svg  logo-lockup-tagline.png
    logo-lockup-stacked.svg  logo-lockup-stacked.png
    logo-lockup-dark.svg  logo-lockup-dark.png  logo-lockup-sand.svg
    app-icon-1024.png  app-icon-maskable-512.png
    social-card.svg  social-card.png
    brand-hero.jpg  brand-hero-640.jpg    ← campaign key visual (and a 640 px web version)
    campaign-poster.jpg                   ← A4 poster, 1240 × 1754
```

Every file above is generated from the geometry in `tools/brand.mjs`:

```bash
node tools/make-assets.mjs            # sources + PNGs (needs @resvg/resvg-js for the PNGs)
node tools/make-assets.mjs --svg-only # sources only, no renderer needed
```

`src/ui/mark.js` is written by the same command — the app's mark is a data URI, never a fetched
file, so the "no network requests" guarantee holds. `npm run check` fails the build if anything
external slips in.

The browser tab, the installed icon, the welcome screen and the sharing card therefore all show the
same seed. If you change the mark, change it in `tools/brand.mjs` once and re-run:

```bash
node tools/make-assets.mjs && npm run build && npm run verify
```

## 9. Do / don't, at a glance

**Do** keep the seed below the sprout · keep the 4° tilt · keep the hyphen green · leave `X` clear
space · print on cream or midnight · set the tagline in both languages · write like a teacher.

**Don't** straighten, mirror or redraw the mark · add gradients or shadows · put the mark on a photo
without a plate · use sprout green for warnings or amber for text · introduce a third tagline
language order · call it "KS Learn", "KSLEARN", "Ks-Learn" or "KSL".
